Pattern Counts

The occurrence count for a pattern includes all performances containing a longer pattern that starts with it. For example, if a pianist plays (0, 3, 0, 1, 2) 100 times, those instances are also counted among the occurrences of (0, 3, 0, 1). Shorter patterns will therefore always have counts greater than or equal to any longer pattern that extends them.
